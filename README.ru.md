# HALVETH Project0 Keeper

**Краткий путеводитель по проекту · Русский**

В [немецком README](README.md) есть ссылка на публичное портфолио работ HALVETH. В документированном снимке от 28 сентября 2026 года репозиторий был пуст и не получил сертификат работы в издании 1.1. Позже появился локальный прототип TRIAD; исторический статус сертификата от этого не меняется.

`scripts/Invoke-Triad.ps1` читает ветку Git, HEAD, изменённые пути и недавние коммиты этого репозитория. ASTER записывает наблюдение, RACHEL добавляет фиксированные альтернативные прочтения, а SHELLA при наличии изменений проверяет незастейдженные и застейдженные изменения через `git diff --check`. Состояние и журнал записываются только в игнорируемый Git каталог `.triad-runtime/`. Версионированный `constellation/REPOSITORIES.json` — исторический снимок, а не актуальный список репозиториев GitHub. Скрипт не изменяет исходный код, не запускает других агентов и не записывает данные в GitHub.

Для локальной проверки нужны PowerShell 7 и Git: `pwsh -NoProfile -File ./scripts/Test-Triad.ps1`, затем `pwsh -NoProfile -File ./scripts/Invoke-Triad.ps1 -Cycles 1`. [Workflow проверки](.github/workflows/triad-integrity.yml) проверяет синтаксис, реестр ролей, три локальных цикла и отсутствие изменений исходных файлов. [Описание ролей](constellation/README.md).

## Права и область применения

Упомянутые в оригинале сертификаты работ HALVETH являются частной документацией проектов, а не институциональными персональными квалификациями или сертификацией ISTQB.

Для соответствующих файлов и версий действуют исходные уведомления о правах и лицензиях. Этот путеводитель не предоставляет дополнительных разрешений.
