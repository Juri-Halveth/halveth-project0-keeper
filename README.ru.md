# TRIAD · локальное управление проектами

Инструменты PowerShell и файлы состояния для экспериментального управления ASTER, RACHEL и SHELLA. Исходники описывают наблюдение, непрерывность, решения и проверки; торгового сервиса или сервиса доходности здесь нет.

## Запустить один цикл наблюдения

Потребуются Git и PowerShell 7. Из каталога репозитория запустите один локальный цикл.

```powershell
pwsh -NoProfile -File ./scripts/Invoke-Triad.ps1 -Cycles 1
```

ASTER читает ветку, коммит и список изменённых файлов. RACHEL сравнивает коммит с предыдущим сохранённым циклом. SHELLA проверяет подготовленные и неподготовленные изменения. При смене коммита или ошибке чтения предыдущего состояния история также помечается для проверки. Решение записывается в `.triad-runtime/STATE.json`.

[Тест исполнения](scripts/Test-TriadRuntime.ps1) использует два временных репозитория и меняет коммит, сохраняя список изменённых файлов.

В [локальном каталоге источников](catalog/HALVETH_CAPABILITIES.json) указаны восемь модулей, их задачи и проверенные версии файлов. Команда `./scripts/Show-HalvethCapabilities.ps1 -IncludeNotes` показывает ссылки и хеши SHA-256 в автономном режиме.
